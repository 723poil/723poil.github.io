## 풀고 싶었던 문제

운영 담당자가 PG 결제 내역을 느리게 조회하고 엑셀로 수기 대조해야 해서 정산 검증 시간이 길고 오류 가능성이 있었습니다.

## 접근 방식

정산 검증용 데이터를 별도로 적재하고, PG 결제 내역 파일과 내부 결제 내역을 1:1로 비교하는 흐름을 만들었습니다.

## 구현한 것

- NestJS Scheduler로 검증 데이터를 생성했습니다.
- Vue3 관리자 화면에서 PG 파일 업로드와 대조 결과 확인 흐름을 제공했습니다.
- 운영자가 불일치 내역을 빠르게 확인할 수 있도록 결과를 상태별로 나누었습니다.

## 달라진 점

결제 내역 조회 시간은 60초 이상에서 10초 이내로 줄었고, 정산 검증 업무는 1시간~1일에서 30분 이내로 단축됐습니다.
