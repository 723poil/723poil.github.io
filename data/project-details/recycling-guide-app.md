## 풀고 싶었던 문제

분리수거 앱들이 품목별 정보 전달에 머무르는 경우가 많아, 사용자가 사진을 찍어 자신의 지역 기준에 맞는 분류 방법을 바로 확인하기 어려웠습니다.

## 접근 방식

재활용 물품 사진을 서버로 전송하면 딥러닝 모델이 물품을 분류하고, 서버가 지역별 분리수거 기준에 맞는 안내를 내려주는 흐름으로 설계했습니다.

## 구현한 것

- Node.js 서버와 Google Cloud 기반 배포 환경을 구성했습니다.
- TensorFlow 모델을 탐색하고 적용 가능성을 검토했습니다.
- Android 앱의 API 연동과 버퍼링 기능 구현을 담당했습니다.

## 달라진 점

짧은 개발 기간 안에 대구 지역 기준의 분리수거 안내를 제공하는 앱 흐름을 구현했고, 팀원과 함께 발표 자료와 프로젝트 제안 발표까지 마무리했습니다.
