## 🧾 요약

경북대학교 팀 프로젝트로, 사진 기반 재활용 물품 분류와 지역별 분리수거 안내를 제공하는 Android 앱을 개발했습니다.

서버 구축과 Android API 연동을 담당했고, 사용자가 촬영한 이미지의 분류 결과를 바탕으로 대구 지역 기준의 배출 방법을 안내하는 흐름을 구현했습니다.

## 🔍 문제

기존 분리수거 안내 앱은 사용자가 품목을 직접 찾아보는 방식이 많아, 실제로 버리려는 물건이 어떤 기준으로 분류되는지 바로 확인하기 어려웠습니다.

또한 분리수거 기준은 지역마다 차이가 있기 때문에, 단순 품목 안내가 아니라 사용자의 지역 기준에 맞는 정보를 제공하는 흐름이 필요했습니다.

## 🛠️ 개선 과정

Node.js 서버와 Google Cloud 기반 배포 환경을 구성하고, Android 앱에서 서버 API를 호출할 수 있도록 연동했습니다. 사용자가 사진을 업로드하면 서버가 분류 결과와 지역별 배출 기준을 연결해 안내 데이터를 내려주는 흐름으로 설계했습니다.

재활용 물품 자동 분류에 활용할 수 있는 오픈소스 이미지 분류 모델을 찾아 적용 가능성을 검토했고, TensorFlow로 연결해 서버 흐름 안에서 사용할 수 있도록 구성했습니다. 팀원들과 함께 이미지 판별 결과를 앱 화면에서 사용할 수 있도록 API 응답 구조를 맞췄고, Android 앱에서는 API 연동과 버퍼링 기능 구현을 담당했습니다.

## 📈 성과

짧은 개발 기간 안에 대구 지역 기준의 분리수거 안내를 제공하는 앱 흐름을 구현했습니다.

프론트엔드 2명, 백엔드 2명으로 구성된 팀에서 서버 구축과 Android 연동을 맡았고, 발표 자료와 프로젝트 제안 발표까지 함께 마무리했습니다.
