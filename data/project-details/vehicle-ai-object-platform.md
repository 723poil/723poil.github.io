## 🧾 요약

경북대학교 종합설계 팀 프로젝트로, 차량 전방 영상의 객체 인식 결과와 운전자 졸음 감지 결과를 차량용 임베디드 보드에서 활용할 수 있도록 연결하는 플랫폼을 개발했습니다.

저는 TOPST 보드에서 main-core와 MCU 코어 간 IPC 통신 제어를 담당하고, 차량·사람 검출 모델 학습에 필요한 이미지 라벨링 작업을 함께 수행했습니다. 외부 보드에서 전달된 인식 데이터를 TOPST 보드 내부의 MCU 코어까지 전달하고, 이후 CAN 데이터로 확장할 수 있는 흐름을 검증했습니다.

## 🔍 문제

TOPST 보드는 외부 장치와 통신하는 main-core와 CAN 통신을 담당하는 MCU 코어가 분리된 구조였습니다. 따라서 외부에서 전달된 차량 검출 및 졸음 감지 데이터를 바로 CAN 데이터로 사용할 수 없었고, main-core에서 수신한 데이터를 MCU 코어까지 안정적으로 전달하는 내부 통신 흐름이 필요했습니다.

또한 프로젝트 당시 TOPST 보드는 처음 다루는 차량용 보드였기 때문에, 코어 구조와 IPC 프로토콜을 이해하고 실제 데이터가 정상적으로 전달되는지 단계적으로 확인해야 했습니다.

## 🛠️ 개선 과정

TOPST 보드에서 제공하는 코어 간 IPC 구조를 분석하고, main-core에서 MCU 코어로 데이터를 전달하는 흐름을 구현했습니다.

AI 모델 학습 데이터 준비 과정에서는 차량 센서 위치와 유사한 구도의 이미지에서 차량과 사람을 구분해 라벨링했습니다. 근거리 위험 감지를 목적으로 하는 프로젝트였기 때문에, 검출 대상이 되는 객체 기준을 팀 내에서 맞추고 모델 학습에 사용할 수 있는 형태로 데이터를 정리했습니다.

main-core에서는 수신한 데이터 유형을 구분한 뒤 IPC를 통해 MCU 코어로 전달하도록 구성했습니다. MCU 코어에서는 전달받은 `cameraNum`, `class`, 좌표, 크기 데이터를 파싱하고 출력해 정상 수신 여부를 확인했습니다.

검증 과정에서 `cameraNum`과 `class`는 정상적으로 출력되었지만, 좌표값이 비정상적으로 표시되는 문제가 있었습니다. 원인을 확인한 결과 RTOS 환경에서 float 출력이 제한될 수 있다는 점을 발견했고, 좌표 데이터를 int 형태로 변환해 출력하도록 수정했습니다.

수정 후 main-core에서 전달한 값과 MCU 코어에서 확인한 값이 일치하는 것을 검증했습니다.

## 📈 성과

외부 보드에서 생성된 AI 인식 결과가 TOPST 보드의 main-core를 거쳐 MCU 코어까지 전달되는 내부 데이터 흐름을 구현했습니다.

이를 통해 TOPST 보드 내부에서 코어 간 IPC 통신이 정상적으로 동작하는 것을 확인했고, MCU 코어에서 수신 데이터를 파싱해 CAN 데이터 전송으로 확장할 수 있는 기반을 마련했습니다.

CAN 장비를 통한 최종 외부 통신 테스트는 산학협력사 일정상 진행하지 못했지만, CAN 전송 직전 단계까지 데이터 전달과 파싱 흐름을 검증했습니다.
