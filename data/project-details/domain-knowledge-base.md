## 풀고 싶었던 문제

주문, 결제, 정산 도메인 지식이 사람과 맥락에 흩어져 있어 반복 질문이 생기고 개발 중 같은 내용을 다시 찾는 일이 많았습니다.

## 접근 방식

업무 지식을 문서 단위로 정리하고, 개발자가 필요한 순간 바로 확인할 수 있는 지식베이스 형태로 묶었습니다.

## 구현한 것

- 주문, 결제, 정산 중심의 도메인 문서를 정리했습니다.
- 반복 질의를 줄일 수 있도록 확인 경로와 용어를 맞췄습니다.
- AI 도구가 참고하기 좋은 단위로 문서 구조를 나눴습니다.

## 달라진 점

반복 질의 중심 업무를 문서 기반 확인 구조로 전환했고, 개발 중 도메인 맥락을 더 빠르게 확인할 수 있게 했습니다.
