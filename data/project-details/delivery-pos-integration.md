## 풀고 싶었던 문제

외부 배달앱 주문이 POS 안에서 주문과 매출로 이어져야 했지만, 주문 수신과 처리 흐름을 매장 운영 방식에 맞춰 연결해야 했습니다.

## 접근 방식

외부 주문 데이터를 POS에서 처리 가능한 형태로 중계하고, 주문 상태와 매출 반영 흐름을 기존 운영 구조에 맞췄습니다.

## 구현한 것

- PHP 서버에서 외부 배달앱 주문 데이터를 수신하고 변환했습니다.
- Java Android POS 앱에서 주문 수신과 처리 화면을 연결했습니다.
- 테스트 매장에서 실제 주문 수신과 처리 흐름을 검증했습니다.

## 달라진 점

외부 배달 주문이 POS 안에서 자연스럽게 처리되도록 연결했고, 테스트 매장에서 실제 주문 수신과 처리까지 확인했습니다.
