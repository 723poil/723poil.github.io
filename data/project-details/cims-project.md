## 🧾 요약

COVID19 정보 관리 시스템(CIMS)을 Python, PyQt5, Firebase 기반 데스크톱 관리 프로그램으로 개발했습니다.

팀 프로젝트에서 백엔드 개발과 Firebase 연동을 담당했고, 사용자·관리자·장소·신고·알림 데이터를 관리하는 흐름을 구현했습니다.

## 🔍 문제

프로그램 안에서 사용자 정보, 장소 정보, 신고 내역, 코로나 관련 정보, 알림 데이터를 함께 다뤄야 했습니다. 단순 화면 구현만으로는 데이터 흐름이 복잡해질 수 있어 역할별 기능을 나누고, Firebase와 연결되는 구조를 정리할 필요가 있었습니다.

원래는 FCM을 활용해 알림을 전달하려 했지만, pyrebase 사용과 token 처리 제약으로 실제 FCM 알림을 적용하기 어려웠습니다. 그래서 알림 전달 방식을 그대로 고집하기보다, 프로젝트 범위 안에서 동작 가능한 대체 구조가 필요했습니다.

## 🛠️ 개선 과정

Python에서 Java의 package 개념처럼 역할을 분리하기 위해 User, Place, Report, Notification, Covid 관련 기능을 폴더 단위로 나눴습니다. 각 영역에서 Firebase 데이터와 연결되는 기능을 분리해 관리하고, 로그인·회원가입·관리자 화면과 데이터 목록 화면이 필요한 정보를 조회할 수 있도록 연결했습니다.

알림은 FCM 대신 Firebase DB에 알림 데이터를 저장하고, `read flag`로 확인 여부를 관리하는 방식으로 설계했습니다. 전체 사용자에게 전달할 알림과 특정 사용자에게 전달할 알림을 DB에 저장하고, 프로그램에서 알림 버튼을 눌렀을 때 읽지 않은 알림을 확인하도록 처리했습니다.

또한 PyQt5 기반 UI와 백엔드 기능을 연결하면서 회원 목록, 관리자 목록, 장소 목록, 신고 목록, 알림 목록을 화면에서 확인하고 관리할 수 있도록 정리했습니다.

## 📈 성과

로그인, 회원가입, 사용자·관리자·장소·신고 목록 관리, 기본 알림과 신고 알림 확인 기능을 포함한 COVID19 정보 관리 프로그램을 완성했습니다.

외부 푸시 알림을 바로 적용하기 어려운 상황에서도 Firebase DB와 상태값을 활용해 프로젝트 범위 안에서 동작 가능한 알림 흐름을 만들었고, 발표와 보고서까지 마무리했습니다.
