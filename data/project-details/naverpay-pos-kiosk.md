## 풀고 싶었던 문제

POS와 KIOSK에 네이버페이 결제 진입점을 붙여야 했지만, 기존 신용카드와 현금 결제 흐름에는 영향을 최소화해야 했습니다.

## 접근 방식

기존 결제 프로세스는 유지하고, 네이버페이 결제가 필요한 지점에만 별도 분기와 상태 처리를 추가했습니다.

## 구현한 것

- PHP 기반 POS 결제 흐름에 네이버페이 요청 경로를 추가했습니다.
- Java Android KIOSK 화면에서 네이버페이 결제 진입점을 연결했습니다.
- 결제 결과가 기존 주문 처리 흐름으로 자연스럽게 이어지도록 상태를 맞췄습니다.

## 달라진 점

기존 신용카드와 현금 결제에 주는 영향을 줄이면서 POS와 KIOSK에서 네이버페이 결제를 사용할 수 있게 했습니다.
