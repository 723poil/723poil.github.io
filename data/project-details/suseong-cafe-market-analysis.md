## 🧾 요약

대구 수성구 카페 자영업자를 위한 상권 분석 서비스를 팀 프로젝트로 개발했습니다.

공공데이터와 제공받은 카페 판매 데이터를 분석해 행정동별 상권 정보를 제공하고, 기상 데이터를 활용해 메뉴별 예상 판매량을 보여주는 흐름을 구성했습니다.

## 🔍 문제

대구시와 수성구의 공공데이터를 활용해야 했지만, 프로젝트에 필요한 상권 정보가 바로 분석 가능한 형태로 정리되어 있지는 않았습니다. 행정동별 업종 정보, 평균 영업기간, 음식점 위치 정보처럼 필요한 데이터가 여러 화면과 기준에 흩어져 있어 직접 수집하고 가공해야 했습니다.

특히 수성구 상권분석 페이지에서 제공하는 데이터는 서비스 화면에서는 확인할 수 있었지만, 분석에 바로 사용할 수 있는 정리된 파일 형태로 확보하기 어려웠습니다. 그래서 직접 서비스 페이지를 크롤링해 데이터를 가져오고, 수집한 데이터를 행정동과 업종 기준으로 정리해 분석에 활용했습니다.

## 🛠️ 개선 과정

Python과 Selenium을 활용해 수성구 상권분석 페이지의 데이터를 크롤링했습니다. 행정동별로 휴게음식점, 한식음식점, 중식음식점, 일식음식점, 패스트푸드점, 식육-구이집의 평균 영업기간을 수집하고, Pandas로 CSV 형태의 분석 데이터로 정리했습니다.

공공데이터와 크롤링 데이터, 연계 기업에서 제공받은 카페 판매 데이터를 함께 분석했습니다. 최종적으로 행정동별 남녀 비율, 평균 연령, 연간 평균 유동인구, 업종별 평균 영업기간과 같은 상권 정보를 구성했습니다.

Google Cloud 환경에 Docker 기반으로 Node.js, MongoDB, Nginx, TensorFlow를 연동해 서버를 구축했습니다. 서버에서는 수집·가공된 상권 정보를 제공하고, 기상 데이터 기반 메뉴 판매량 예측 모델을 클라이언트에서 사용할 수 있도록 연결했습니다.

## 📈 성과

지도에서 수성구 행정동을 선택하면 해당 지역의 카페 위치와 상권 정보를 확인할 수 있는 분석 서비스를 구현했습니다.

날씨 정보와 판매 데이터를 기반으로 메뉴별 예상 판매량을 제공하는 흐름을 만들었고, 프로젝트 결과는 UCWIT 2022 한국정보과학회 학술심포지엄 논문으로 기재되었습니다.
